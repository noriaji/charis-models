Motion model for Charis Viewer's "Motion Between Poses" feature (NVIDIA MotionBricks, SOMA). The file is an unmodified copy of NVIDIA's original; nothing was retrained or changed.

The viewer downloads it only when a user presses the download button. It runs on the user's own PC and no pose data is sent anywhere. The viewer checks the size and the SHA-256 before it uses the file.
